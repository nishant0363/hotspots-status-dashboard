📘 Interpretation

Data Generation Normalization & Classification
• Each hotspot is evaluated within ~150m radius
• Demand = number of orders near the hotspot
• Idle Supply = number of idle experts near the hotspot
• Avg Idle Time = average idle time of experts within radius
• Computed using geo-distance (Haversine method) 		• Sarjapur used as baseline cluster
• Median demand per hotspot calculated for each cluster
• Scaling factor = (cluster median / Sarjapur median)
• Thresholds dynamically scaled using this factor
• Categories assigned:
No → Sparse → Moderate → Yes
• Ensures fair comparison across clusters with different densities
